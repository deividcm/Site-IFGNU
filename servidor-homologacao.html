Servidor de Homologação

Apenas os responsáveis pelo servidor de homologação tem acesso, para subir o sistema é necessário o usuário entregar o acesso ao repositório pelo formulário Solicitação de Homologação de Sistema. Durante o processo de homologação os sistemas receberão subdomínios customizados e terão que seguir normas semelhantes com as do TI, serão usadas ferramentas de escaneamento indicadas como Nessus e OWASP. Caso nenhum problema ocorra a equipe enviará uma mensagem confirmando que o sistema passou e será sugerido aos desenvolvedores que solicitem a hospedagem com o TI. As regras para este servidor estão em Regras Servidor de Homologação.pdf .
