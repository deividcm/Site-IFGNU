Perguntas Frequentes

Equipe com várias pessoas:

Para uma melhor organização apenas uma pessoa será responsável por configurar o sistema no servidor então apenas um usuário será criado e responsabilizado pelo sistema.

Erros Comuns

O Sistema caiu de um dia pro outro:

Quando o servidor desliga/cai, como por exemplo quando a energia cai, todos os sistemas caem juntos. Para que eles reiniciem quando o servidor ligar de novo é necessário colocar a instrução “restart: unless-stopped” no arquivo docker-compose.yml, ela faz com que o sistema reinicie a não ser que alguém tenha manualmente derrubado ele. Caso você queira que o sistema reinicie até mesmo em casos que ele foi derrubado manualmente basta trocar a tag “unless-stopped” por “always”. Lembrando que mesmo usando “always” o sistema só reinicia após o Docker reiniciar.

Erro “You don’t have permission to access this resource. Server unable to read htaccess file, denying access to be safe”:

O erro ocorre quando o conteúdo do sistema não foi copiado corretamente pelo Docker, geralmente quando você tenta forçar o Docker a utilizar arquivos dentro do seu usuário.
