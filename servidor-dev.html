Servidor de Desenvolvimento

Os usuários terão acesso para desenvolver e testar os sistemas dentro do ambiente de um servidor, para receber o acesso é necessário preencher o formulário Solicitação de Acesso ao Servidor. Após o preenchimento dos formulários haverá um prazo de até 7 dias para entrega do acesso e então o usuário deverá preencher o formulário Solicitação de Hospedagem de Sistema e aguardar a confirmação para cada sistema que deseje subir. As regras para a utilização deste servidor estão em Regras do Servidor Dev
